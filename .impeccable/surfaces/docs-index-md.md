# Homepage surface brief

## Scope and mode

- Target: `docs/index.md`
- Mode: Read
- Related surface: `docs/spec/registry.md`

## Reader, job, and action

Framework authors and agent builders need to understand within one viewport that ASC is a semantic control layer, see how its five constructs remain distinct, and enter the code registry by numeric class. The primary action is to browse `1xxx`–`9xxx`; the secondary action is to read ASC 0.1 or implement the envelope.

## Chosen direction

Public-infrastructure wayfinding applied to status routing. The approved north-star comp is `.impeccable/mocks/asc-home-registry-atlas.png`. The memorable moment is the nine edge-to-edge class bands functioning as the protocol's front door.

The class index is literal product navigation. The route diagram is explanatory, not a claim that the five constructs are sequential or interchangeable. Motion is limited to one slow route trace and disappears under reduced motion.

## Fidelity inventory

| Ingredient | Commitment | Medium |

| Masthead | Compact wordmark, draft marker, four durable destinations | Existing semantic Zensical navigation, restyled with CSS |

## Component grammar

- Square geometry and clipped corners only where a directional marker needs them; no rounded card grid.
- One-pixel ink rules, flat colour fields, no elevation or gradients.
- Condensed wayfinding display face for navigation and headings; hyperlegible grotesk for reading; monospaced numerals for codes.
- Large display, compact labels, and comfortable body measure form the type ramp.
- Route colours are semantic navigation roles, never decoration scattered across prose.

## Constraints

ASC 0.1 remains visibly experimental. No adoption claims. The homepage may be expressive; normative pages must remain calm, accessible, printable, and fast to scan. Preserve light/dark system preferences, keyboard navigation, reduced motion, and narrow-screen usability.
