# Font licences

The website self-hosts Latin WOFF2 subsets of three typefaces distributed under
the SIL Open Font License 1.1:

- [Atkinson Hyperlegible](https://github.com/googlefonts/atkinson-hyperlegible),
  created by the Braille Institute;
- [Barlow Condensed](https://github.com/jpt/barlow), created by Jeremy Tribby;
  and
- [Source Code Pro](https://github.com/adobe-fonts/source-code-pro), created by
  Adobe.

The subset files were obtained from Google Fonts. Each upstream repository
contains the complete copyright notice and licence text for its typeface.
